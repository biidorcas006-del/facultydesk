# Lecturer Dashboard Database

This folder contains the persistent SQLite database used by `server.js`.

- Database file: `lecturer-dashboard.db`
- It is created automatically if missing.
- Demo students are seeded only when the `students` table is empty.
- Keep this folder when moving the project to another computer.
- Do not delete `lecturer-dashboard.db` unless you want to reset the local data.

Start the backend from the project root with:

```bash
npm install
npm run dev
```
